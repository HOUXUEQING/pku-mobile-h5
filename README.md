## 页面功能

- **集团组织架构**
  - 北大医疗集团为根节点
  - 北京、天津、山东、山西、湖南、广东 6 大地区为分支
  - 点击地区节点直接筛选对应机构

- **按地区查找**
  - 全部地区、北京、天津、山东、山西、湖南、广东
  - 显示各地区机构数量

- **搜索**
  - 支持按机构名称、中心名称、地址、电话、地区、机构类型搜索
  - 支持清空搜索与结果数量反馈

- **机构类型筛选**
  - 综合医院 5 家
  - 康复医院 2 家
  - 专科医院 1 家
  - 健康管理中心 4 家

- **成员机构目录**
  - 机构卡片直接展示机构地址、联系电话、机构类型
  - 卡片内直接提供「拨打电话」「复制地址」
  - 点击机构或「查看机构详情」打开详情侧边栏
  - 详情内支持查看同地区其他机构

- **汇报辅助**
  - 使用附件中的北大医疗 logo
  - 深色页头使用浅色透明版 Logo，页脚使用原色透明版 Logo
  - slogan 使用楷体书法风
  - 「打印 / 导出」可直接使用浏览器打印或另存为 PDF
  - 打印样式自动隐藏筛选与操作区

## 数据说明

附件中的机构信息按以下结构整理：

- 北京地区：北京大学国际医院、北京北大医疗康复医院、方园中心、望京中心、北三环中心、金融街中心
- 天津地区：北大医疗海洋石油医院
- 山东地区：北大医疗鲁中医院、北大医疗淄博医院
- 山西地区：北大医疗潞安医院（含长治分院区）
- 湖南地区：北大医疗恺德心血管病医院
- 广东地区：深圳北医康复医院

机构名称、地址、电话均依据附件整理；正式对外使用前建议由品牌/法务再次核验。

## 部署

正式上线前建议：
- 核验机构名称、地址、电话与分院区信息
- 补充机构官网/地图跳转（如需要）
- 对接企业微信或企康专员咨询入口
- 按企业 VI 替换品牌字体与色值

- 首页顶部两组数据统计已去掉横向分隔线和纵向分隔线
